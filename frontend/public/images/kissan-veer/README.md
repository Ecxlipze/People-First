# Kissan Veer page images

Artwork for the `/kissan-veer` page, based on the Kisaan Veer Subpage mockup.
The page currently uses these uploaded PNG files:

- `hero-farmland.png` — wide farmland sunrise background with technology overlay; ideally at least 1920px wide, without heading text or navigation.
- `farmer-illustration.png` — farmer ploughing with oxen in the introductory quote panel; transparent background preferred.
- `crop-map.png` — aerial crop/field map shown inside the Crop Intelligence Dashboard.
- `ai-plant.png` — glowing turquoise plant/circuit illustration in the AI Advisory panel; transparent background preferred.

Optional: add original service and ecosystem icons in an `icons/` subfolder if available.

Dashboard values are illustrative sample data; advisory and market buttons open the contact modal.
Existing People First branding and the Kissan Veer venture logo are reused.
